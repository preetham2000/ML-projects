# ML Projects

A collection of self-contained machine-learning and reinforcement-learning projects covering model implementation, experimentation, evaluation, and reproducible reporting.

## Projects

| Project | Description | Environment |
| --- | --- | --- |
| [Classical ML from scratch](machine-learning/classical-ml-from-scratch/) | NumPy implementations of LDA, QDA, OLS, ridge regression, and polynomial regression, with public datasets and reference tests. | Python 3.10+; tested with Python 3.13 |
| [AUV depth control](reinforcement-learning/auv-depth-control/) | Hand-written DDPG and TD3 agents plus an illustrative LQI controller for a simplified AUV depth-control simulation. | Tested with Python 3.11.10 |

Each project has its own README and dependency file. Create a separate virtual environment inside the project directory, then follow that project's setup, run, and test instructions.

Curated figures and machine-readable result summaries are tracked for review. Locally generated training runs, checkpoints, caches, and editor files are ignored.
